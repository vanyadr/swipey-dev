# Заготовки для учеников

Шаблоны подготовлены по текущим компонентам приложения. В них сохранены разметка, статические надписи, классы, атрибуты и иконки. Вместо значений и обработчиков стоят заглушки с комментариями `TODO`. Хуков, данных фильмов и реализаций обработчиков нет.

## Как использовать

Скопируйте нужный файл из `templates/components` в `src/components` или из `templates/pages` в `src/pages`, заменив рабочую реализацию. Можно отправлять файлы по одному по мере прохождения тем. Чтобы использовать весь комплект, скопируйте обе папки в `src`.

`HomePage` и `GradientBackground` не включены в комплект: используйте уже написанные файлы. Сохраните существующие `App.tsx`, роутер, `App.css`, CSS-сброс, зависимости и изображения. `model.ts` и `data.json` остаются в проекте и доступны для подключения во время занятия; шаблоны их не импортируют.

## Что дописать

- Получение props и их типов в общих компонентах. В шаблонах параметры названы `_props`, значения временно необязательные, а тип фильма — `unknown`. При подключении данных замените его на `Movie` и сделайте нужные props обязательными.
- Состояния, эффекты, ref и переходы между страницами.
- Данные в отмеченных местах JSX: имена, сведения о фильме, ссылка, ошибки и текст кнопки после копирования.
- Обработчики вместо `onClick={undefined}`, `onChange={undefined}`, `onSubmit={undefined}` и `onDragEnd={undefined}`. В обработчиках отправки формы нужно вызвать `preventDefault()`.
- Условия отображения блоков и классов, перебор списка фильмов через `.map()` и ключи элементов. В заготовке оставлен один элемент списка и разметка всех состояний; комментарии отмечают, какие блоки должны показываться по условию.
- Значения `disabled`, параметры анимации и подключение камеры.

Пустые строки, `undefined`, `false` и нули в отмеченных местах — заглушки, а не готовая логика. Например, `Intro` пока не выводит `children`, а форма пока не обновляет состояние. Заготовки предназначены для постепенного дополнения на занятии.

Стили уже есть в `src/App.css`. Для постера сохраните базовый класс `poster`, добавляйте `poster--<id фильма>` и, для маленькой карточки, `poster--small`. У выбранных вкладок используются классы `active` и `selected`.
